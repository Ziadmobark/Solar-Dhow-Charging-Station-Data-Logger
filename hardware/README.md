# Hardware Design Files

This directory contains the KiCad source files for the Solar Dhow charging-station data logger PCB designed by Ziad Mobark.

The project-local symbol, footprint, and required 3D-model files are included so the design can be opened without relying on the original workstation paths.

Firmware/software and enclosure CAD files are intentionally not included. They were developed/designed by other project team members.
